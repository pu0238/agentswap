[span] 01 · The problem
[h2] Agents can pay. Just not in the right token.
[span] x402 lets an agent pay for an HTTP call, but on Solana that means USDC.
[span] Services price in SOL, stables, memecoins and their own tokens.
[span] Swapping today means a DEX UI and a wallet popup. An agent can't click through that.
[span] 02 · The fix
[h2] A swap that speaks
[span] HTTP.
[span] The price comes as a machine-readable 402, so the agent's x402 client pays it automatically.
[span] Jupiter finds the best route across Solana DEXs.
[span] We return an unsigned transaction. The agent signs it and sends it itself.

[span] 07 · Trust model
[h2] Non-custodial
[span] by design.
[p] AgentSwap builds transactions and never signs them. If our server disappeared tomorrow, no agent would lose a cent.
[span] Keys
[span] Never sent to us. The response is an unsigned VersionedTransaction.
[span] Slippage
[span] Bounded at 1–1000 bps, 50 by default, and enforced on-chain by the route.
[span] Payment
[span] The x402 fee is settled only when the swap build succeeds. A failed request is never charged.
[span] State
[span] None. A stateless Cloudflare Worker with no database and no accounts.
