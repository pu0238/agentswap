01 · The problem

Agents can pay. Just not in the right token.

Ax402 lets an agent pay for an HTTP call, but on Solana that means USDC.
BServices price in SOL, stables, memecoins and their own tokens.
CSwapping today means a DEX UI and a wallet popup. An agent can't click through that.
02 · The fix

A swap that speaks HTTP.

AThe price comes as a machine-readable 402, so the agent's x402 client pays it automatically.
BJupiter finds the best route across Solana DEXs.
CWe return an unsigned transaction. The agent signs it and sends it itself.

# → 402 Payment Required until your x402 client pays
TypeScript agent@x402/fetch · @solana/kit
import { wrapFetchWithPayment } from "@x402/fetch";
import { x402Client } from "@x402/core/client";
import { ExactSvmScheme } from "@x402/svm/exact/client";
import { getBase64Encoder, getTransactionDecoder, signTransaction } from "@solana/kit";

// pays the 402 and retries automatically
const paidFetch = wrapFetchWithPayment(fetch,
  new x402Client().register("solana:*", new ExactSvmScheme(signer)));

const res = await paidFetch("$API/api/swap", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ from: "USDC", to: "SOL", amount: "1", userPublicKey: signer.address }),
});
const { swapTransaction } = await res.json();

// your key never leaves the agent
const tx = getTransactionDecoder().decode(getBase64Encoder().encode(swapTransaction));
const signed = await signTransaction([signer.keyPair], tx);

07 · Trust model

Non-custodial by design.

AgentSwap builds transactions and never signs them. If our server disappeared tomorrow, no agent would lose a cent.

  • KeysNever sent to us. The response is an unsigned VersionedTransaction.
  • SlippageBounded at 1–1000 bps, 50 by default, and enforced on-chain by the route.
  • PaymentThe x402 fee is settled only when the swap build succeeds. A failed request is never charged.
  • StateNone. A stateless Cloudflare Worker with no database and no accounts.
