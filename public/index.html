The site wants something else.

AgentSwap lets AI agents swap any listed Solana token in one HTTP call. Pay $0.01 per swap through x402 and get back an unsigned transaction. The agent signs it, so we never hold keys or funds.

Give it to your agent API reference

How it works

01 · free

Quote

GET /api/quote returns a live price from Jupiter, which searches every major Solana DEX.

02 · $0.01 via x402

Pay & build

POST /api/swap replies with 402. The agent's x402 client pays in USDC and retries, then gets an unsigned transaction.

03 · non-custodial

Sign & send

The agent signs the transaction with its own key and sends it to any RPC. The tokens go straight to its wallet.

API

EndpointPriceWhat it does
GET /api/tokensfreeSupported tokens (symbol, mint, decimals)
GET /api/quote?from=USDC&to=SOL&amount=1freeLive quote. Amounts are in human units.
POST /api/swap$0.01 USDC · x402Returns an unsigned VersionedTransaction (base64) for userPublicKey
POST /mcpfreeMCP server with list_tokens, get_quote and swap_info

Try it

# 1. quote (free)
curl "https://agentswap.example/api/quote?from=USDC&to=SOL&amount=1"

# 2. swap (x402 paid). Without payment you get HTTP 402 plus a PAYMENT-REQUIRED header
curl -X POST https://agentswap.example/api/swap \
  -H 'content-type: application/json' \
  -d '{"from":"USDC","to":"SOL","amount":"1","userPublicKey":"<wallet>"}'
// TypeScript agent with @x402/fetch + @solana/kit
const paidFetch = wrapFetchWithPayment(fetch,
  new x402Client().register("solana:*", new ExactSvmScheme(signer)));
const { swapTransaction } = await paidFetch(`${API}/api/swap`, { method: "POST", body }).then(r => r.json());
// decode → signTransaction([signer.keyPair], tx) → rpc.sendTransaction(...)

Add it to Claude Code as an MCP server:

claude mcp add --transport http agentswap https://agentswap.example/mcp
AgentSwap is a hackathon proof of concept. Swaps are routed through Jupiter on Solana mainnet. It is non-custodial: you sign every transaction yourself. Use small amounts.
